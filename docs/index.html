From airfoil to workshop

One model. Every part.

DesignRC keeps the aerodynamic definition, structure, 3D preview, plans, and exported parts connected—so a design change flows through the entire wing.

01

Parametric wing geometry

Define connected panels with independent chord, sweep, twist, dihedral, rib spacing, and root and tip airfoils. DesignRC mirrors the half-wing into the complete aircraft.

02

Built-up structure

Generate ribs, tapered root-to-tip spars, shear webs, front, rear, and trailing-edge sheeting, collision-checked joiners, spoilers, hinge posts, flaps, and ailerons.

03

True solid preview

Inspect the assembled wing in an interactive OpenCascade viewport with orbit, pan, zoom, material colors, and STEP export.

04

Manufacturing output

Create a tightly packed, full-scale poster plan and export selected laser-cut parts as vector DXF, SVG, or PDF files.

05

Exact workshop units

Work globally in millimeters or inches, override units per parameter, and display exact 1/32-inch values as familiar fractions.

New in version 1.1.0

More control over the structure.

Version 1.1.0 expands spar, sheeting, spoiler, and joiner design while refining manufacturing geometry and validation throughout the application.

01

Swept spars and advanced sheeting

Set independent root and tip spar locations. Control where Front sheeting stops, recess covered spars, and add independent constant-width Top and Bottom TE Sheeting with optional tapering.

02

Spar-aware spoilers

Place spoilers immediately behind the top spar and receive clearer collision reports for frame rails, spars, trailing edges, and adjoining spoiler parts.

03

Improved joiners

Updated fixed, wood, and removable joiners preserve rib material through dihedral joints, detect overlaps, and model rods extending into their mating sleeves.

A direct path to fabrication

Design. Inspect. Export.

Move from imported airfoil coordinates to build-ready parts without rebuilding the same geometry in separate CAD and drawing tools.

  1. 01

    Define the wing

    Set panel geometry, import Selig-style airfoils, and configure the internal structure.

  2. 02

    Generate and inspect

    Build the solid model, verify the complete mirrored wing, and refine the design.

  3. 03

    Make the parts

    Export full-scale plans, cutting files, and the complete material-colored assembly.

  4. 04

    Continue in CAD

    Download the STEP file and import the wing assembly into your favorite CAD tool.

Choose your platform.

DesignRC is available for 64-bit Windows and Linux. Every installer is published with source archives and SHA-256 checksums.

W

Windows 11 · x64

Windows installer

Guided per-user installation with the application graphics and runtime dependencies included.

Download .exe ↓ Windows may warn because the installer is not code-signed.
D

Debian / Ubuntu · amd64

Debian package

Includes Qt 6.4.2, OCCT 8.0, and ICU 74 while APT resolves system runtime libraries.

Download .deb ↓ sudo apt install ./designrc_1.1.0_amd64.deb
F

Fedora · x86_64

Fedora package

Native RPM package tested in Fedora 44 with required dependencies resolved by DNF.

Download .rpm ↓ sudo dnf install ./designrc-1.1.0-1.x86_64.rpm
