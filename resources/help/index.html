What DesignRC does

DesignRC is a desktop CAD application for designing built-up radio-control airplane wings. You describe one half-wing with one or more connected panels. DesignRC interpolates the airfoil and planform, generates the internal structure and manufacturing geometry, then mirrors the result into a complete wing.

  • Imports Selig-style root and tip airfoil .dat files.
  • Interpolates airfoil shape, chord, sweep, twist, and rib stations across each panel.
  • Builds solid ribs, riblets, spars, shear webs, sheeting, leading and trailing edges, control surfaces, hinge posts, spoilers, wiring holes, and fixed or removable joiners.
  • Displays a material-colored Open CASCADE solid assembly in an interactive 3D viewport.
  • Creates a flattened, annotated, full-scale technical plan of both wing halves.
  • Exports plans and laser-cut parts to vector PDF, parts to DXF/SVG/PDF, and the 3D assembly to STEP.
  • Saves editable projects as .designrc files.
Design convention: panel parameters describe the right half-wing from the aircraft centerline outward. DesignRC generates that half and mirrors it for the complete preview, plan, and assembly.

The main window

Wing Actions toolbar
Contains Generate Wing, Generate Plan, Export Plan PDF, Export Parts, and Export STEP. Downstream actions remain disabled until their required geometry or plan exists.
Panel editor
The left side contains the number of wing panels, one editor tab per panel, and vertically arranged parameter pages.
3D View
The right-side solid-model viewport. It opens blank for a new project until Generate Wing is pressed.
Plan View
The flattened technical drawing. This tab is enabled after Generate Plan.
Metrics
Reports full wingspan, full wing area, aspect ratio, and taper ratio after successful generation.
Status bar
Shows navigation hints and generation progress. A progress bar and Cancel button appear while geometry is being built.

Recommended workflow

  1. Choose the number of connected half-wing panels.
  2. Set each panel's span, chords, sweep, dihedral, twist, airfoils, and ribs.
  3. Add spars, sheeting, edge stock, joiners, controls, spoilers, wiring holes, and optional lightening features.
  4. Press Generate Wing to validate the design and build the complete 3D assembly.
  5. Inspect the assembly with orbit, pan, zoom, Fit View, and the preset camera buttons.
  6. Press Generate Plan to build the full-scale flattened drawing.
  7. Save the project and export the plan, selected parts, or STEP assembly.

Editing parameters marks the existing preview and plan as out of date. DesignRC does not automatically rebuild expensive geometry, allowing several related values to be changed first.

Units and value entry

The project-wide length unit is millimeters or inches. Geometry is stored internally in millimeters, so changing display units does not resize the wing.

Global, mm, and in selectors

The User Defaults dialog shows a selector beside every length:

Global
Use the current global length unit.
mm
Always display and edit this parameter in millimeters.
in
Always display and edit this parameter in inches.

Per-parameter unit overrides are saved and are also used for matching annotations.

Entering measurements

  • Inch controls accept decimals, fractions such as 3/16, and mixed values such as 1 1/2.
  • Spinner arrows advance inch fields by 1/32 inch. Exact 1/32-inch values display as reduced fractions.
  • You may type an explicit suffix such as 12 mm, 0.5 in, or 1/4". The field converts the value and adopts that explicit unit override.
  • Angle fields are always displayed in degrees. Percent fields represent chordwise position.

Multi-panel wings

Number of Wing Panels
Selects 1–12 connected panels in one half-wing. Changing the count adds or removes panel editors after confirmation where necessary.
Panel 1
The center panel. Its root chord and root airfoil are editable, and it can use Rib 1a and centerline-only features.
Panels 2–12
Each outer panel inherits the preceding panel's tip chord and tip airfoil as its root values.

Shared ribs are oriented to bisect the angle between adjoining panels. The 3D model includes dihedral, while the plan flattens the panels to true manufacturing length.

Specs tab

Airfoils

Import root .dat
Loads the normalized root profile on Panel 1. Outer-panel roots are inherited.
Import tip .dat
Loads the panel-tip profile. Intermediate ribs morph between the root and tip profiles.

Dimensions

Panel Span
Flattened root-to-tip length of this half-wing panel.
Root / Tip Chord
Airfoil chord at the panel ends. Root Chord is editable only on Panel 1.
Tip Sweep
Fore/aft displacement of the tip leading edge from the root leading edge.
Dihedral
Panel angle used when assembling adjoining panels in 3D.
Tip Twist
Progressive wash-in or wash-out from zero at the root to the entered tip angle.

Ribs tab

Rib Count
Number of regular rib stations including root and tip. The calculated center spacing is displayed below it.
Rib Thickness
Sheet thickness used for solid ribs, slots, rib faces, and member endpoints.
Add Rib 1a
Panel 1 only. Adds a center-section reinforcement rib midway between the first two regular stations; later rib labels adjust accordingly.
Lightening Holes
Creates optimized circular rib holes over the selected rib range while honoring minimum border and inter-hole distances. This can significantly increase generation time.
Riblets
Adds one or more partial ribs per bay over the selected range. Riblets require a carbon-fiber leading edge and a mid-position CF spar between 20% and 40% chord.

Spars tab

Use Add Spar to create any number of spar definitions. Check spar headings and press Delete Checked to remove selected rows.

Chord Location
Position as a percentage of local airfoil chord.
Top / Bottom / Mid
Places the spar against the upper surface, against the lower surface, or through the airfoil interior.
Wood
Creates a rectangular spar using Height and Width and cuts matching rib notches.
CF Tube
Creates a carbon tube with OD and ID and cuts aligned rib holes.
CF Rod
Creates a solid carbon rod with the selected OD.
CF Strip
Creates rectangular carbon strip stock using Width and Thickness.
Shear Webs
Available when matching top and bottom wood spars share a chord location. Creates individual web parts between rib faces using the selected thickness.

Sheeting tab

LE Top / Bottom Sheeting
Recesses the matching rib surface and builds curved sheeting between the leading-edge system and the applicable spar boundary.
TE Top / Bottom Sheeting
Builds recessed curved sheeting from the spar region toward the trailing-edge system.
Stop Rib Number
Last rib covered by a sheet that begins at the panel root.
Turbulators
Adds 1–4 longitudinal square-section strips. LE sheeting is divided around enabled turbulators.

Joiners tab

Choose whether the panel joint is Fixed or Removable. Changing panel type deletes incompatible joiner rows after confirmation.

Fixed Panel

Add Fixed Joiner creates rows at an entered chord location. A fixed joiner may be:

  • a one-piece V-shaped wood joiner aligned with matching upper and lower wood spars;
  • a carbon-fiber tube or rod; or
  • a steel rod.

Removable Panel

Sleeve/Rod Joiner
Defines which side of the joint carries the sleeve and rod, their materials, diameters, and corresponding adjoining-panel parts.
Alignment Pin
Defines either a sleeve/pin arrangement or a pin/hole arrangement, including side, material, and diameter.
Delete Checked
Removes the selected fixed or removable rows.

Joiner axes and rib openings are oriented through the joint geometry so panels assemble at the intended dihedral. Fixed and removable tube or rod joiners are raised above the camber line at each joint rib by the same amount that they fall below the camber line at the adjoining rib, preserving equal rib material above and below the joiner. Alignment pins are excluded from this balancing rule. At the wing center, a wood joiner passes through R1 and also R1a when that optional rib is present, then stops against the inner face of R2. At an outboard panel joint, it extends one rib bay into each panel, passes through only the two ribs at the joint, and stops against the inner faces of the next ribs. Each rib the wood joiner passes through is bisected into two manufacturing pieces. Invalid wood-spar alignment is rejected because a wood joiner cannot bend through a swept joint.

LE/TE tab

Leading edge

Block LE Stock
Removes the rib noses at the selected width and lofts smooth wood stock from the airfoil profiles at the member ends. Height must accommodate every cut rib.
CF Tube LE
Creates an exposed carbon tube and circular rib cradles. OD defines the outside; ID defines the bore.
CF Rod LE
Creates a solid exposed carbon rod and matching rib cradles.

Trailing edge

Sheet TE Stock
Removes the rear rib profile and lofts smooth sheet stock matching the airfoil-derived top and bottom surfaces.
Slotted for Ribs
Extends ribs into open-ended slots in the trailing-edge stock for keyed assembly.

Ailerons/Flaps tab

Ailerons and flaps are separate, closed solids. Each is one smooth spline loft between the airfoil-derived profile at its start and the profile at its end; intermediate rib outlines are not imprinted on the control surface.

Width
Chordwise depth measured forward from the trailing edge.
Height
Nominal control body height setting.
Start / Stop Rib
Spanwise boundaries. Flaps stop before a panel tip; an aileron may extend through the tip rib.
Hinge Post Width / Height
Cross-section of the separate fixed hinge-post solid ahead of the movable control.
Wiring Holes
Adds rectangular wiring openings through the selected ribs using start/end ribs, chord location, width, and height.
  • A clearance gap is maintained around movable controls.
  • When flap and aileron meet at one rib, their widths must match and DesignRC creates a continuous hinge post.
  • Aileron Start Rib cannot precede Flap Stop Rib.

Spoilers tab

Spoilers
Builds a recessed spoiler panel, forward and aft frame rails, and end support rails over the selected rib range.
Start / End Rib
Defines the spoiler span. A center spoiler requires zero dihedral.
Start Chord Location
Positions the spoiler assembly as a percentage of local chord.
Chordwise Length / Thickness
Defines the spoiler panel.
Frame Rail Width
Width of the surrounding frame rails. Support Rail Height is calculated and displayed.
Lightening Holes
Adds optimized holes to the spoiler using minimum border and circle spacing.
Wiring Holes
The same synchronized wiring-hole definition shown on the Ailerons/Flaps page.

Generate Wing

Generate Wing validates every panel and then builds ribs, openings, members, controls, joiners, material solids, the mirrored assembly, and display meshes. Progress messages identify the active stage. Cancel requests a safe stop after the current geometry operation.

Successful generation enables Generate Plan, Export Parts, and Export STEP. A failed generation reports the specific panel or component and leaves the last valid preview intact.

3D View

Left drag
Orbits around the assembly.
Right drag
Pans the camera.
Mouse wheel
Zooms in and out.
Fit View
Fits the complete assembly in the viewport.
Reset / presets
Reset restores the default camera; Top, Bottom, Front, Back, Left, and Right select orthographic directions.

Parts are colored by material: wood, carbon fiber, aluminum, steel, and fiberglass are visually distinct. Part edges remain visible for assembly inspection.

Plan View and plan PDF

Generate Plan creates a flattened drawing of both wing halves at manufacturing dimensions. It includes rib outlines and labels, spars, sheeting, edge stock, controls, spoilers, hinge posts, joiners, dimensions, panel spans, dihedral and twist notes, metrics, borders, and a title block.

Left drag
Pans the drawing.
Mouse wheel
Zooms the drawing.
Fit View
Fits the full plan when Plan View is active.
Export Plan PDF
Writes a vector PDF on a custom page sized to the complete drawing. Geometry is exported at 1:1 scale.
Changing any design parameter invalidates the plan. Generate Wing and Generate Plan again before exporting a revised plan.

Parts export

Export Parts lists all available ribs and split rib halves, riblets, shear webs, sheet-stock parts, wood joiners, spoilers, and one dihedral-angle template per panel. A rib bisected by a wood joiner is exported as two separate closed pieces in its part drawing.

DXF / SVG / PDF
Select one or more output formats. DXF and SVG are suitable for CAD and laser workflows. A combined PDF places all selected parts tightly on one custom-size poster page at full scale; trailing-edge stock is oriented with its length horizontal.
Initial selection
No parts are selected when the dialog opens. OK remains disabled until at least one format and one part are selected.
All Parts
Exports all generated part drawings into one combined file for each selected format. The PDF is one poster-size page rather than letter-size tiles.
Select All / None
Checks or clears the entire list.
Individual parts
Creates a separate file named from each checked part.

DXF and SVG use millimeters for reliable CAD import. Exported ribs include generated holes, notches, slots, lightening geometry, and split-piece outlines.

STEP assembly export

Export STEP writes the current generated 3D model as a named assembly. Individual wood, carbon-fiber, aluminum, steel, and fiberglass components remain separate assembly parts with material colors. STEP export requires a current successful Generate Wing operation.

User Defaults

Edit > Defaults controls the starting state for new projects:

  • global millimeter or inch display;
  • default number of connected panels;
  • geometry worker threads, up to the available CPU thread count minus one;
  • complete parameter defaults for every panel; and
  • per-parameter Global/mm/in choices and default rows for spars and joiners.

Saving User Defaults does not overwrite the current project. New projects use the saved settings; a fresh installation uses the version-1.0 installed defaults.

Validation and automatic corrections

DesignRC checks parameter ranges and geometric feasibility before and during generation. Examples include overlapping controls, shared control widths, spoiler range and center-dihedral rules, wiring-hole fit, riblet prerequisites, LE/TE stock height, spar and joiner collisions, tube dimensions, wood-joiner alignment, and failed solid Boolean operations.

When only one valid correction exists, DesignRC may adjust a related field and explain the change. Otherwise generation stops with a message identifying what must be corrected.

Manufacturing responsibility: inspect exported geometry, material choices, clearances, structural loads, and machine settings before cutting or flying. DesignRC does not certify structural strength or airworthiness.
